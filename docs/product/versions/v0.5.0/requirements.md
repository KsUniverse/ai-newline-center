## 2. F-006-1：视频-文案关联

### 2.1 入口

**路径**：我的账号页 → 点击视频卡片 → 视频详情弹层（SlidePanel）→ 弹层内的"关联文案"区域

### 2.2 关联操作流程

1. 用户在视频详情弹层底部看到"关联文案"区域
2. 若尚未关联：显示"关联文案"按钮
3. 点击按钮 → 打开选择对话框（Dialog）
4. 对话框展示仿写任务列表（筛选条件：**当前登录员工**创建的、至少有一个 `isFinalVersion=true` 的 `RewriteVersion` 的仿写任务）
5. 每条仿写任务显示：目标账号昵称、仿写模式（工作台/直接创作）、话题（直接创作模式）或对标视频标题（工作台模式）、最终稿内容预览（前 100 字）、创建时间
6. 用户选择一条仿写任务 → 点击确认
7. 系统创建 `VideoRewriteLink` 记录，关联该视频与选中仿写任务

### 2.3 已关联状态

- 弹层中显示已关联的仿写任务摘要（目标账号昵称 + 内容预览）
- 提供"解除关联"按钮

### 2.4 取消关联

- 用户点击"解除关联" → 确认对话框
- 确认后删除 `VideoRewriteLink` 记录
- 弹层恢复未关联状态

### 2.5 数据约束

| 约束 | 描述 |
|------|------|
| 一视频一关联 | 一个 `DouyinVideo` 最多关联一个仿写任务（唯一约束） |
| 一稿多视频 | 同一仿写任务可被多个视频关联（同稿多账号发布场景） |
| 仿写范围 | 仅当前登录员工的、`isFinalVersion=true` 的仿写任务 |
| 权限 | 员工只能关联/解除自己的视频（视频归属的账号须属于当前用户） |

### 2.6 验收标准

1. 视频详情弹层中展示关联文案区域
2. 关联选择器中只展示当前员工有最终稿的仿写任务
3. 关联成功后弹层展示已关联仿写摘要
4. 解除关联后恢复未关联状态
5. 同一视频不能重复关联（提交时验证）
6. 非视频所有者无法执行关联操作（后端校验）

## 3. F-006-2：数据趋势展示

### 3.1 入口

**路径**：视频详情弹层 → 数据趋势区域（折线图）

### 3.2 图表内容

- 横轴：时间（按快照 `timestamp` 排列）
- 纵轴：数量
- 曲线：播放量、点赞数、评论数、转发数（4 条线）
- 时间范围：默认展示最近 7 天的快照数据

### 3.3 数据来源

`VideoSnapshot` 表（已存在）：
- `playsCount`、`likesCount`、`commentsCount`、`sharesCount`
- `timestamp`（采集时间）
- 快照采集定时器已在 scheduler 中配置（每 10 分钟）

### 3.4 边界处理

| 场景 | 处理 |
|------|------|
| 快照数 < 2 | 显示空状态提示"数据采集中，稍后刷新可查看趋势" |
| 快照数 ≥ 2 | 正常渲染折线图 |
| API 请求中 | 显示 skeleton |

### 3.5 验收标准

1. 视频详情弹层中展示数据趋势区域
2. 折线图包含播放量/点赞/评论/转发 4 条曲线
3. 快照数不足时展示空状态提示
4. 快照数据按时间升序展示（最早在左）
